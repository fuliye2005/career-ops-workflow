# Career Flow Studio

**基于 Career-Ops 的 AI 求职工作流项目。** 它把岗位评估、个人档案、技能匹配、定制简历和面试准备放进一套可本地运行的 workflow 中，适合通过 Codex 等 AI Agent 协作完成求职准备。

> 网页负责个人资料和岗位的管理、编辑与展示；需要模型分析或生成的工作，由你正在使用的 Agent 按 Career-Ops 能力完成。网页本身不调用模型，也不会自动投递。

## 项目包含什么

- **Career-Ops 求职能力**：沿用上游项目的岗位分析、简历定制、面试准备、求职流程管理等能力。
- **岗位工作台**：集中查看岗位 JD、匹配评估、修改建议、技能提升建议、面试准备与简历产物。
- **模块化个人档案**：分开管理基本信息、教育、工作/实习经历、项目和技能，并用熟悉度标注可讲程度。
- **定制简历**：依据岗位和档案中已有事实生成 HTML 初稿；可在网页中继续编辑。不会把 JD 要求的技能自动写成候选人事实。
- **本地优先**：资料、岗位记录和生成文件保存在本机工作目录中；工作流不代替用户提交申请或联系招聘方。

## Agent 与网页如何配合

```text
你与 Agent 对话
      ↓
Agent 使用 Career-Ops 能力分析岗位、准备技能建议/面试材料、生成简历初稿
      ↓
本地 workflow 保存岗位记录与 HTML 文件
      ↓
网页负责浏览、管理和编辑；最终决定与投递由你本人完成
```

例如，你可以在 Agent 中说：“根据当前档案评估这个岗位，并生成一份可编辑的定制简历。”岗位总览页用于查看和打开结果；它不是一个会自行连接大模型的聊天网页。

## 本地运行

需要 Node.js。克隆项目并安装依赖后，在项目目录启动 Agent：

```bash
git clone https://github.com/fuliye2005/career-ops-workflow.git
cd career-ops-workflow
npm install
npm run workflow:serve
codex
```

在浏览器打开 `http://127.0.0.1:4173/` 查看本地工作台；再在项目目录启动 Codex，并用自然语言要求 Agent 评估岗位、生成定制材料或开展面试模拟。完整步骤、示例和截图位置见[使用教程](使用教程.md)。

> 仓库名调整后，请将上面的 clone 地址替换为 GitHub 上显示的新地址。

## 资料与事实边界

- 公开演示档案使用化名和虚构示例信息，不代表真实求职者或真实履历。
- 实际使用前，请用本人可核实的信息替换演示档案，并检查本地 Git 更改，避免把真实个人信息提交到公开仓库。
- 简历内容应只来自个人档案和本人明确提供的信息；岗位要求是匹配标准，不是候选人事实。
- 技能熟悉度表示能否在面试中说明，不应为了匹配岗位而自动调高。

本项目基于 [santifer/career-ops](https://github.com/santifer/career-ops) 开源项目进行工作流整合和本地展示扩展。上游提供跨 AI coding Agent 使用的 career-ops 能力；本项目补充面向岗位与个人档案的网页工作台及配套流程。请同时参阅仓库中的 [`LICENSE`](LICENSE) 与上游项目说明。
